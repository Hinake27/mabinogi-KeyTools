# 瑪奇模糊鑰匙盒解碼器

用來協助解開「打開模糊不清的盒子」小遊戲。工具會建議下一組要在遊戲中輸入的數字，並根據每次回饋逐步縮小答案範圍。

直接開啟 `index.html` 即可使用，不需要安裝或連線。

## 介面說明

- **建議數字**：顯示下一個建議猜測的數字。
- **輸入結果**：輸入遊戲回饋的結果（三位數字）。
- **可能性**：顯示剩餘的可能答案數量。
- **重新開始**：重置遊戲，回到初始狀態，並產生新的隨機首組建議。
- **確認**：提交當前輸入的結果。

結果三位數依序代表：

1. 綠色數量：數字和位置都正確。
2. 黃色數量：有這個數字，但位置錯誤。
3. 紅色數量：答案中沒有這個數字。

例如 `120` 代表 1 個綠色、2 個黃色、0 個紅色。

## 使用方式

1. 將工具顯示的建議數字輸入遊戲。
2. 仔細查看遊戲顯示的綠、黃、紅符號數量。
3. 依序輸入三位數結果，例如 `102`。
4. 按下「確認」，取得下一組建議數字。
5. 重複操作，直到工具顯示唯一答案。

## 注意事項

- 請確保輸入的是三位數字。
- 三個數字的總和必須等於 3。
- 如果輸入錯誤，可以使用「撤銷上一筆」或「重新開始」。
- 工具會記錄所有猜測歷史，並據此計算下一個建議數字。
- 「可能性」顯示為「無」或「條件矛盾」時，表示之前的輸入可能有誤。

## 建議策略

- 使用工具顯示的建議數字進行猜測。
- 工具有時會顯示「探測碼」。探測碼不一定是答案，但能更快排除大量可能性，請照樣輸入遊戲測試。
- 仔細確認遊戲顯示的符號，再輸入結果。
- 如果結果異常，先撤銷上一筆並重新核對；必要時重新開始。

## 技術支援

- 使用純 HTML、CSS、JavaScript 開發。
- 可離線使用，不需要網路連接。
- 支援主流現代瀏覽器。
